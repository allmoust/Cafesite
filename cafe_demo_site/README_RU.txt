Что внутри:

ВАЖНО:
Это портфолио-демо. Кафе «Morgenrot», адрес, телефон, e-mail, часы работы, меню и цены выдуманы. Не выдавай этот сайт за настоящий бизнес. Перед публикацией для клиента нужно заменить все данные на согласованные с владельцем и получить разрешение на использование его фото/логотипа.

КАК ПОКАЗАТЬ ДЕМО ЧЕРЕЗ GITHUB PAGES:
1. На GitHub создай НОВЫЙ репозиторий, например cafe-demo. Не загружай эти файлы поверх NEXUS GAMING.
2. Открой репозиторий → Add file → Upload files.
3. Распакуй ZIP на компьютере и загрузи index.html, style.css и README_RU.txt (можно загрузить README отдельно).
4. Нажми Commit changes.
5. В Settings → Pages выбери Deploy from a branch, branch main, folder /(root), затем Save.
6. Подожди появления ссылки в разделе Pages и открой её.

КАК ИЗМЕНИТЬ ТЕКСТ:
Открой index.html в репозитории и нажми значок карандаша. Ищи слова Café Morgenrot, Musterstraße, цены и контакты. Меняй только на данные, которые владелец бизнеса подтвердил.

КАК ИЗМЕНИТЬ ЦВЕТА:
В начале style.css есть блок :root. Например --green задаёт зелёный цвет, --cream — фон.
